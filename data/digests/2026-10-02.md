## Top stories

### DeepSeek releases its agent harness as MIT-licensed open source in public preview

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://www.deepseek.com/en/harness/), [repository](https://github.com/deepseek-ai/deepseek-harness), [discussion](https://news.ycombinator.com/item?id=49929489)
- **Blurb:** DeepSeek released its agent harness as MIT-licensed open source in public preview, runnable via npx or desktop.
- **Summary:** DeepSeek published its agent harness under the MIT license in public preview, built on an everything-is-a-plugin architecture. It runs as a desktop application or through `npx`.
- **Why it matters:** A frontier lab shipping an MIT harness adds a second credible open base for building agents alongside Pi, which reached 1.0 a day earlier.

### Claude Code adds mods, TypeScript functions that intercept its events

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://claude.com/blog/claude-code-mods), [docs](https://code.claude.com/docs/en/plugins/mods/overview), [discussion](https://news.ycombinator.com/item?id=49925102)
- **Blurb:** Claude Code adds mods, unsandboxed TypeScript functions that intercept its events and can rewrite or block calls.
- **Summary:** Mods are TypeScript functions that hook Claude Code events. They can rewrite prompts, block or retry tool calls, answer permission requests, and redact tool output. They run unsandboxed with the same machine access as Claude Code.
- **Why it matters:** Installing a mod is equivalent to running untrusted code with full local access, except that on Team and Enterprise plans and on any machine with managed settings a built-in `sec-default` mod loads first and stops user-installed mods from overriding permission deny rules.
- **Follow-up:** Whether mods widen the coding-agent sandbox-escape surface tracked since the 2026-07-20 Docker-socket and Cowork VM disclosures.

### SvelteKit 3 moves configuration into vite.config.ts and renames the $lib alias

- **Category:** Dev tools
- **Status:** confirmed
- **Sources:** [primary](https://svelte.dev/blog/sveltekit-3-is-here), [discussion](https://news.ycombinator.com/item?id=49926536)
- **Blurb:** SvelteKit 3 moves configuration into vite.config.ts, renames the $lib alias to #lib, and changes env handling.
- **Summary:** SvelteKit 3 relocates configuration into `vite.config.ts` and replaces the `$lib` alias with the `#lib` subpath import. Environment variables, service workers, and error handling also change. Remote functions remain unshipped, behind an experimental Async Svelte flag.
- **Why it matters:** Existing apps need a migration pass across config location, imports, environment variables, service workers, and error handling.

## ML research

### Context Language Models let the model edit its own context as a file

- **Category:** Paper
- **Status:** confirmed
- **Sources:** [paper](https://arxiv.org/abs/2609.37725), [discussion](https://news.ycombinator.com/item?id=49922437)
- **Blurb:** Context Language Models let a model edit its own context as a file, reporting 11.4% higher BrowseComp-Plus accuracy.
- **Summary:** The paper treats the context window as a file the model updates itself rather than a buffer managed by an external harness. On BrowseComp-Plus the authors report 11.4% higher accuracy at 21.5% fewer FLOPs than external context management. The figures are the authors' own and are not independently reproduced.
- **Why it matters:** Context management is the layer agent harnesses currently own, so moving it inside the model changes what a harness is responsible for.

### arXiv caps submitters at two submissions per calendar month

- **Category:** Infrastructure
- **Status:** confirmed
- **Sources:** [primary](https://blog.arxiv.org/2026/10/01/updated-rate-limit-policy/), [discussion](https://news.ycombinator.com/item?id=49926512)
- **Blurb:** arXiv now caps each submitter at two submissions per calendar month after monthly volume doubled to 40,363.
- **Summary:** Effective 2026-10-01, arXiv limits each submitter to two submissions per calendar month on top of the standing three-active-submission limit. Rejected submissions count against the cap and pre-announcement deletions do not. The post states monthly volume doubled in two years to 40,363.
- **Why it matters:** Anyone posting preprints now plans release timing around a hard monthly cap rather than a soft queue.
