## Top stories

### Claude Code makes auto mode the default permission mode on 2026-08-14

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://claude.com/blog/auto-mode-default-in-claude-code), [docs](https://code.claude.com/docs/en/auto-mode-config), [discussion](https://news.ycombinator.com/item?id=49227253)
- **Summary:** Anthropic states in a post dated 2026-08-07 that starting 2026-08-14 new sessions on Pro, Max, and Team plans run in auto mode, the permission mode in which a classifier decides which commands run without a prompt. A user who set a different default may get a one-time prompt, and a pinned default is unchanged. The announcement cites a controlled study in which human review of prompts detected a planted dangerous command 13.6 percent of the time against 89 percent for the classifier.
- **Why it matters:** The permission model most Claude Code sessions run under changes on a fixed date, so teams that rely on per-command prompts have until 2026-08-14 to pin the mode explicitly.
- **Follow-up:** Confirm the rollout on 2026-08-14.

### Head Mare exploits unpatched TrueConf servers to ship backdoored client installers

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://www.bleepingcomputer.com/news/security/hackers-breach-trueconf-to-trojanize-client-installers-with-backdoors/), [discussion](https://news.ycombinator.com/item?id=49224274)
- **Summary:** The Head Mare group compromised unpatched on-premise TrueConf conferencing servers and replaced the client installers those servers distribute with backdoored builds. The trojanized clients are unsigned. BleepingComputer reports the affected versions as TrueConf Server 5.3.x before 5.3.9, 5.4.x before 5.4.9, 5.5.x before 5.5.5, and older releases, fixed in 5.3.9, 5.4.9, and 5.5.5 published 2026-06-18.
- **Why it matters:** A compromised on-premise conferencing server hands a backdoored client to everyone who connects to it, including partner organizations that never operated TrueConf themselves.

### UTM publishes Triton, a DirectX 11 user-mode driver for QEMU Windows guests

- **Category:** Dev tools
- **Status:** confirmed
- **Sources:** [primary](https://blog.getutm.app/2026/introducing-triton-directx-11-driver-for-qemu/), [discussion](https://news.ycombinator.com/item?id=49221711)
- **Summary:** UTM released Triton, a user-mode driver that provides DirectX 11 graphics acceleration to Windows guests running under QEMU. Triton implements the driver interface rather than replacing system DLLs. The announcement is dated 2026-07-24 and reached Hacker News on 2026-08-08.
- **Why it matters:** Implementing the driver interface is what lets desktop compositing and applications that detect modified system files work under QEMU, instead of dropping DLLs per application.

## Security

### Craft CMS 5.10.5 fixes a passkey login that accepts replayed WebAuthn assertions

- **Category:** Security
- **Status:** confirmed
- **Sources:** [advisory](https://github.com/advisories/GHSA-wg23-69c2-gjc8), [release](https://github.com/craftcms/cms/releases/tag/5.10.5)
- **Summary:** Craft CMS accepted a WebAuthn assertion that had already been used, so a captured passkey login request body authenticates again. GHSA-wg23-69c2-gjc8 gives the affected range as 5.0.0-RC1 up to but excluding 5.10.5, patched in 5.10.5. GitHub rates it Critical at CVSS 9.1 and no CVE is assigned.
- **Why it matters:** One captured login request creates further authenticated sessions for that account, which removes the one-time challenge guarantee that passkeys are chosen for.

## Outages

### Cloudflare restores R2 objects unavailable for about 32 hours after an ENAM write failure

- **Category:** Outage
- **Status:** confirmed
- **Sources:** [status](https://www.cloudflarestatus.com/incidents/9fzfjzc5ms0h), [discussion](https://news.ycombinator.com/item?id=49224478)
- **Summary:** A write failure in a small set of R2 buckets in Cloudflare's ENAM region left a small number of objects unreadable, specifically ones uploaded through multipart upload during a two-hour window on 2026-08-07. The incident page records the first update at 2026-08-07 18:42 UTC and a final update stating availability was fully restored at 2026-08-09 02:35 UTC, which is a span of about 32 hours. The page states the incident affected Cloudflare Sites and Services (R2) and carries no severity rating.
- **Why it matters:** The affected objects returned errors for more than a day rather than for the length of the write failure, so an application reading them saw what looked like durable loss while the status page tracked the write path.

## Infrastructure

### RFC 10023 defines a _for-sale DNS leaf node name

- **Category:** Infrastructure
- **Status:** confirmed
- **Sources:** [primary](https://www.rfc-editor.org/rfc/rfc10023.html), [discussion](https://news.ycombinator.com/item?id=49221668)
- **Summary:** RFC 10023, dated July 2026, specifies a `_for-sale` leaf node name carrying TXT records, used to signal that a registered domain is available to buy. The convention requires no protocol change. It reached Hacker News on 2026-08-08.
- **Why it matters:** Registrars and availability services can adopt the signal against zones that already exist, because it rides on TXT records under an underscored leaf name.

### Fastmail adds an Amsterdam data region and lists what stays in the United States

- **Category:** Infrastructure
- **Status:** confirmed
- **Sources:** [primary](https://www.fastmail.com/blog/fastmail-offers-eu-data-region/), [discussion](https://news.ycombinator.com/item?id=49223082)
- **Summary:** Fastmail offers an EU data region hosted in Amsterdam. The post names the parts that do not move, including logs, emergency backups, replicated account metadata, and the geographic replica.
- **Why it matters:** The named exclusions let the residency choice be checked against a compliance requirement instead of taken as a guarantee.
