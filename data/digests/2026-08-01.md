## Top stories

### Microsoft attributes the CaptiveCrunch captive-portal campaign to a Midnight Blizzard sub-cluster

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://www.microsoft.com/en-us/security/blog/2026/07/31/captivecrunch-midnight-blizzard-targets-travelers-worldwide-for-malware-delivery-and-credential-theft/), [discussion](https://www.reddit.com/r/cybersecurity/comments/1vc4525/captivecrunch_midnight_blizzard_russia_targets/)
- **Summary:** Microsoft Threat Intelligence attributes the CaptiveCrunch campaign to Storm-2945, a sub-cluster it places under Midnight Blizzard. The report describes manipulation of DNS and HTTP traffic on captive-portal networks since early May 2026, delivering a Windows remote access trojan written in Go with keylogging, credential and session-token theft, and audio and video capture, and the same landing pages carry instructions for installing an Android APK. It names no affected software or versions, and states that the investigation into how the captive-portal networks were first compromised is ongoing, noting only commonalities in equipment and management systems across affected networks.
- **Why it matters:** An engineer on hotel or conference Wi-Fi is in the targeted population, and the named controls are refusing browser-prompted updates on captive-portal networks and blocking the device code authentication flow in Entra ID.
- **Follow-up:** Track whether Microsoft identifies the initial compromise vector for the affected captive-portal networks.

### Tailscale publishes its own account of how a stolen auth key enrolled 181 nodes in the Hugging Face intrusion

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://tailscale.com/blog/hugging-face-intrusion), [discussion](https://news.ycombinator.com/item?id=49127306)
- **Summary:** Tailscale describes a stolen authentication key used to enroll 181 nodes during the Hugging Face intrusion. The post prescribes replacing reusable auth keys in CI with workload identity federation and enabling network flow logs.
- **Why it matters:** The prescribed change is a configuration any team running Tailscale can apply today rather than a vendor patch to wait for.
- **Follow-up:** Track further first-party accounts of the Hugging Face intrusion from affected vendors.

### The Go Collections working group proposes standard-library sets, hash maps, and ordered maps for Go 1.28

- **Category:** Languages
- **Status:** developing
- **Sources:** [primary](https://github.com/golang/go/issues/80590), [discussion](https://news.ycombinator.com/item?id=49127031)
- **Summary:** The Go Collections working group filed a proposal to add sets, hash maps, and ordered maps to the standard library for Go 1.28. The item is a proposal under discussion, not an accepted change.
- **Why it matters:** A canonical set type in the standard library sets the convention that new Go APIs are expected to follow, which is broader migration pressure than any single package release.
- **Follow-up:** Track the proposal review outcome and whether it lands in the Go 1.28 cycle.

### WASTE streams Kimi K3 from NVMe and decodes at 0.5 tokens per second on a 64 GB laptop

- **Category:** AI
- **Status:** confirmed
- **Sources:** [primary](https://github.com/sqliteai/waste), [discussion](https://news.ycombinator.com/item?id=49123386)
- **Summary:** WASTE keeps a 27.28 GB resident trunk of Kimi K3 in memory and streams only the selected experts from disk, using the remaining RAM as a bounded expert cache. The repository reports decoding at 0.5 tokens per second on a laptop with 64 GB of RAM, against a 982 GiB converted container on internal NVMe and 1.42 TB of staging space to perform the conversion.
- **Why it matters:** It moves a frontier-scale open-weights model onto one consumer machine with terabyte-scale local storage, with no network dependency and no per-token invoice, and it publishes the measurements that bound how useful that is.

## AI

### Artificial Analysis publishes an independent evaluation of DeepSeek V4 Flash 0731

- **Category:** AI
- **Status:** confirmed
- **Sources:** [primary](https://artificialanalysis.ai/models/deepseek-v4-flash), [discussion](https://news.ycombinator.com/item?id=49120299)
- **Summary:** Artificial Analysis published its own measurements for DeepSeek V4 Flash 0731. It places the max-reasoning configuration at an Artificial Analysis Intelligence Index of 49.93 and at 0.027 USD per Intelligence Index task, the lowest cost per task of the 13 models in that chart, against 1.86 for GPT-5.6 Sol and 2.34 for Claude Opus 5 in the same configuration.
- **Why it matters:** Cost per task is the figure a team pays against when choosing an inference provider, and these are Artificial Analysis's own measured datasets rather than vendor-reported numbers.

### Y Combinator publishes qm, an MIT-licensed multiplayer agent harness with per-scope sandboxes

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://github.com/yc-software/qm), [discussion](https://news.ycombinator.com/item?id=49126604)

## Engineering posts

### Manifest describes why it deprecated the LLM router it ran for four months across 7000 users

- **Category:** Engineering post
- **Status:** confirmed
- **Sources:** [primary](https://manifest.build/blog/why-we-deprecated-our-llm-router/), [discussion](https://news.ycombinator.com/item?id=49126630)
- **Summary:** Manifest launched the router in March 2026 and deprecated it in June 2026 after running it across 7000 users. The write-up is what is new, and it argues that prompt text does not carry the task complexity discovered later through tool calls, and that prefix cache reads priced at 75 to 90 percent off make model stickiness cheaper than switching. The router shuts down for good on 2026-09-01.
- **Why it matters:** Both arguments are checkable by any team building routing in front of multiple models, and they come from a vendor arguing against its own shipped feature.
- **Follow-up:** Check that the router shutdown lands on 2026-09-01 for teams still calling it.
