### Debian's LLM general resolution ends with Responsible Use of Generative AI, and the ban option fails its supermajority

- **Category:** Dev tools
- **Status:** confirmed
- **Sources:** [primary](https://vote.debian.org/~secretary/gr_llm/results.txt), [ballot](https://www.debian.org/vote/2026/vote_002), [LWN](https://lwn.net/Articles/1091231/), [discussion](https://news.ycombinator.com/item?id=49486967)

### Proton traces its 2026-08-27 outage to unannounced filter maintenance on both cooling compressors

- **Category:** Outage
- **Status:** confirmed

- **Blurb:** Proton says a datacenter operator replaced air filters on both cooling compressors overnight, unannounced, causing total cooling loss.
- **Summary:** Proton published an incident report attributing its 2026-08-27 outage to a total cooling failure in its Frankfurt datacenter. ### A GCC trampoline hack calls nested functions without an executable stack on releases before GCC 17

- **Category:** Languages
- **Status:** confirmed
- **Sources:** [primary](https://uecker.codeberg.page/2026-08-29.html), [discussion](https://news.ycombinator.com/item?id=49490138)
- **Blurb:** A GCC post reads the code address and static chain out of an emitted trampoline, so nested function pointers avoid an executable stack.
- **Summary:** The post, dated 2026-08-29, describes calling a nested function through its address on GCC releases before 17 without marking the stack executable. It reads the code address and the static chain out of the two immediate constants in the trampoline GCC emits, calls the target through `__builtin_call_with_static_chain`, and clears the executable-stack flag on the resulting binary with patchelf. The trampoline is still emitted and the indirect call still cannot be devirtualized, so the technique buys the stack permission and not the code generation.
- **Why it matters:** Hardened toolchains and kernels reject an executable stack, and this puts the fix on compilers already deployed instead of gating it on an upgrade to a GCC release that no longer requires the trampoline.
