## Top stories

### GitHub Actions and Pages outage runs about 10 hours 40 minutes and drops workflow-triggering events

- **Category:** Outage
- **Status:** confirmed
- **Sources:** [status page](https://www.githubstatus.com/incidents/qcvjkzcs7j74), [discussion](https://news.ycombinator.com/item?id=49198302), [discussion](https://news.ycombinator.com/item?id=49203184), [discussion](https://news.ycombinator.com/item?id=49201459)
- **Summary:** GitHub reported an incident affecting Actions and Pages that ran about 10 hours 40 minutes. GitHub states that push and pull request events not processed during the incident cannot be replayed automatically. Actions Runner Controller pods left stuck by the incident do not recover on their own.
- **Comments:** An Ask HN thread ran while the incident was open. Commenters there compared self-hosted runner registration failures and queue behaviour against the status page wording.
- **Why it matters:** Teams must push a new commit or re-run workflows themselves, and stuck ARC pods need manual kubectl deletion or an ARC redeploy until the next runner release ships automatic recovery.

### Claude Code executes .mcp.json commands at session start, and Anthropic calls it working as designed

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://www.immersivelabs.com/resources/blog/claude-code-rce-vulnerability-how-a-malicious-pull-request-executes-code), [discussion](https://www.reddit.com/r/netsec/comments/1vhh5xw/claude_code_rce_how_a_malicious_pr_triggers_code/)
- **Summary:** Immersive Labs reports that checking out an untrusted pull request branch inside an already-trusted repository and then opening Claude Code runs any command declared in the branch's project-scoped `.mcp.json`. Execution happens before the user types anything and without an active account. Anthropic's bug bounty response states the workspace trust model places the boundary at the folder trust decision, so the behaviour is treated as designed rather than as a defect. No affected Claude Code versions are named and no fix is planned.
- **Why it matters:** The practical control is reviewing `.mcp.json` and `.claude/` as executable code before switching to a contributor branch.
- **Follow-up:** Track whether Anthropic moves the trust boundary below the folder level.

### SCTPhantom use-after-free in Linux SCTP yields root and container-to-host escape (CVE-2026-64564)

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://matrix.tencent.com/en/2026/08/06/sctphantom-CVE-2026-64564), [discussion](https://news.ycombinator.com/item?id=49201059)
- **Summary:** Tencent Zhuque Lab published a use-after-free in the Linux SCTP implementation, rated CVSS v4.0 8.5, from a bug present since Linux 2.6.25. The lab reports local root on Debian 13, Ubuntu 24.04, Rocky Linux 9 and OpenCloudOS, plus container escape in six of eight attempts without CAP_NET_ADMIN or CAP_SYS_ADMIN. First fixed versions are 6.6.148, 6.12.101, 6.18.42, 7.1.6 and mainline 7.2-rc5.
- **Why it matters:** An unprivileged local process on an unpatched multi-tenant host reaches root and, in most reported attempts, the host from inside a container.

### Zapscape KVM guest-to-host escape published with a working proof of concept (CVE-2026-64561)

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://github.com/V4bel/Zapscape), [discussion](https://news.ycombinator.com/item?id=49198843)
- **Summary:** The embargo has ended on a shadow MMU use-after-free in KVM/x86 and the exploit is published on oss-security. A guest with L1 kernel privilege can run code as root on the host. Affected commits span 2020-07-08 to 2026-07-21.
- **Why it matters:** The same bug works as a local privilege escalation on distributions that ship /dev/kvm at mode 0666, so exposure is not limited to virtualization hosts.

## ML research

### Programmatic tool calling matches or beats JSON tool calling in 11 of 14 models on BFCL v4

- **Category:** Paper
- **Status:** developing
- **Sources:** [preprint](https://arxiv.org/abs/2608.06370)
- **Summary:** An unreviewed preprint evaluates exposing tools as typed Python stubs invoked through code, with execution and results handled in one agent turn. It reports a 10.6 percent gain over the JSON baseline for the GPT-5.6 family and parity or better in 11 of 14 models on BFCL v4. Under context rot the programmatic form held stable while the JSON baseline degraded 2.3 percent.
- **Why it matters:** The result is a concrete interface choice for anyone building an agent harness, pending independent replication.

## Agentic coding

### MCP 2026-07-28 specification removes protocol sessions and makes the protocol stateless

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://modelcontextprotocol.io/specification/2026-07-28/changelog), [coverage](https://blog.cloudflare.com/mcp-v2/), [discussion](https://news.ycombinator.com/item?id=49196233)
- **Summary:** The initialize handshake and the `Mcp-Session-Id` header leave the core request path. Elicitation becomes Multi Round-Trip Requests as a breaking change, and new `Mcp-Method` and `Mcp-Name` headers let gateways route without parsing JSON. Roots, Sampling, Logging, Dynamic Client Registration and the legacy HTTP+SSE transport are deprecated under a new 12-month minimum removal window.
- **Why it matters:** Servers can run on request-scoped infrastructure instead of holding per-client state, at the cost of a breaking change to elicitation.

### Humans missed one threat in three approving AI agent commands across 40,000 game runs

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://scalex.dev/blog/ai-agent-permissions-stats/), [coverage](https://www.theregister.com/ai-and-ml/2026/08/06/humans-in-the-loop-miss_a_third_of_dangerous_ai_coding_agent_requests/5284236), [discussion](https://news.ycombinator.com/item?id=49195468)
- **Summary:** Across 409,000 decisions mean accuracy was 66.3 percent, with exfiltration and scope-violation commands missed about three times as often as obviously destructive ones. The command `npm run analyze` was approved 64.7 percent of the time even with the malicious script shown in the log. The figures come from a time-boxed browser game with a 34 percent threat rate and self-selected players rather than from observed production work.
- **Why it matters:** The human-in-the-loop approval prompt is a weak control against commands that do not look destructive.

## Security

### TONTOU attack re-poisons branch predictors after Spectre v2 mitigations run

- **Category:** Security
- **Status:** confirmed
- **Sources:** [coverage](https://www.bleepingcomputer.com/news/security/new-tontou-cpu-attack-bypasses-spectre-v2-fixes-leaks-linux-password-hashes/), [discussion](https://news.ycombinator.com/item?id=49203860)
- **Summary:** MIT CSAIL researchers presented at Black Hat USA a technique that injects timer interrupts into the gap between branch predictor neutralization and use, defeating eIBRS on Intel and Safe RET on AMD. On an AMD Zen 2 Linux host they read arbitrary kernel memory at 5.47 bytes per second with 91.97 percent accuracy and recovered /etc/shadow in five of ten runs. AMD published an advisory the same day. Fixed microcode and kernel versions are not named in the available coverage.
- **Why it matters:** Deployed Spectre v2 mitigations do not stop this variant, and the reported leak rate is low but sufficient to recover password hashes.

### 77 counterfeit Open VSX extensions harvested developer, Git and CI metadata

- **Category:** Security
- **Status:** confirmed
- **Sources:** [coverage](https://www.bleepingcomputer.com/news/security/77-open-vsx-extensions-found-harvesting-developer-info/)
- **Summary:** Manifold Security found extensions on Open VSX impersonating real VS Code Marketplace packages, published between 2026-07-26 and 2026-08-01 and all reporting to mangorbit[.]com. 19 of them collected Git remote hosts, configured email domains, branch and HEAD commit, and identifiers from GitHub, GitLab, Azure DevOps, Buildkite, CircleCI, Codespaces and Gitpod. Open VSX removed them by 2026-08-03.
- **Why it matters:** Registry removal does not uninstall an extension, so affected machines stay compromised until someone audits installed extensions directly.

## Languages and runtimes

### Zig's Io.Threaded cancels blocking syscalls using signals and a shared-memory handshake

- **Category:** Languages
- **Status:** confirmed
- **Sources:** [primary](https://matklad.github.io/2026/08/06/neat-io-threaded.html), [discussion](https://news.ycombinator.com/item?id=49198063)
- **Summary:** The implementation gets cancellation from ordinary blocking syscalls on POSIX by setting a flag and signalling the target until it acknowledges EINTR, and on Windows by calling NtCancelSynchronousIoFile. Zig separates may-run-concurrently from must-run-concurrently at the interface, so thread pooling stays possible.
- **Why it matters:** The approach delivers reliable cancellation without io_uring and without the thread teardown that makes pthread_cancel awkward.

- **Category:** Apple
- **Status:** confirmed
- **Sources:** [coverage](https://www.privacyguides.org/news/2026/08/05/apples-private-relay-leaks-your-real-ip-address-in-safari/)

## Infrastructure

### Cloudflare ships Kitesurf, an agent-first browser running in V8 isolates on Workers

- **Category:** Infrastructure
- **Status:** confirmed
- **Sources:** [primary](https://blog.cloudflare.com/kitesurf/), [discussion](https://news.ycombinator.com/item?id=49196184)
- **Summary:** Cloudflare built the engine in Rust compiled to WebAssembly rather than shipping Chromium.
