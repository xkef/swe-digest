### htmx 4.0.0 makes attribute inheritance explicit and renames every event

- **Category:** Dev tools
- **Status:** confirmed
- **Sources:** [announcement](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released), [discussion](https://news.ycombinator.com/item?id=49478178)

- **Summary:** The release names three breaking changes. - **Why it matters:** Removing default inheritance can drop a CSRF header set on a parent element with no error raised, which is the failure the upgrade check exists to find.

### The OpenAI Python SDK moves to HTTPX2 and changes the default TLS trust store

- **Category:** Languages
- **Status:** confirmed
- **Sources:** [migration guide](https://github.com/openai/openai-python/blob/main/httpx2.md), [httpx2](https://github.com/pydantic/httpx2), [discussion](https://news.ycombinator.com/item?id=49477212)
- **Blurb:** The OpenAI Python SDK's move to HTTPX2 drops certifi for the OS trust store, so TLS can fail in minimal container images.
- **Summary:** The migration guide names a break that reaches applications using the SDK's default client and changing nothing else. HTTPX verified certificates against the certifi bundle, HTTPX2 uses the operating-system trust store, and the SDK no longer installs certifi, so verification can fail in minimal container images with no system CA certificates, behind TLS-inspecting corporate proxies, and anywhere a modified certifi bundle was relied on. The stated fix is installing CA certificates in the OS trust store or setting `SSL_CERT_FILE` or `SSL_CERT_DIR`, the SDK also stops installing httpx transitively, custom transports, auth classes, event hooks and mocking must target httpx2 types, and a RESPX version that patches only legacy HTTPX cannot intercept the default client.
- **Why it matters:** A dependency upgrade that changes the trust store fails at request time in exactly the deployment shapes that carry no system CA bundle.
- **Follow-up:** Track whether the documented legacy HTTPX escape hatch, which is runtime-only and fails static type checking without a cast, is discontinued.
