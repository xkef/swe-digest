### Microsoft Paint and Photos embed a server-issued GUID as an invisible pixel watermark in images generated locally on the device

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://xusheng.dev/posts/reversing/mspaint_invisible_watermark/main/), [discussion](https://news.ycombinator.com/item?id=49421158)
- **Summary:** A reverse-engineering write-up traces a per-generation GUID from a moderation POST, through `Watermarker.dll`, into the pixels of images the local model produces, in Paint 11.2605.71.0 and Photos 2026.11060.2004.0. The author then finds the same value in the signed C2PA soft-binding assertion of a saved PNG, and obtained a live server response to confirm the identifier comes from the service rather than the device. The two applications differ on failure. Paint turns a watermarking failure into a failure of the whole generation, while Photos logs the error and returns the image unmarked.
- **Why it matters:** Local generation still requires a remote moderation call that carries the prompt and returns the per-generation identifier written into the pixels, so the image itself links back to a server-side record.

### SWE Refactor Bench reports 28 of 520 agent runs completing a whole-repository migration

- **Category:** Paper
- **Status:** developing
- **Sources:** [primary](https://arxiv.org/abs/2608.23564)
- **Summary:** The benchmark separates whether a migration actually happened from whether behaviour survived, because an agent can copy the original implementation to pass the tests, which the authors call Blindness. Across 8 frontier models and 26 model-effort configurations, 28 of 520 runs pass all three stages, 5.4 percent, and 13 of the 20 tasks receive no accepted solution. Agents score 31.4 out of 100 on build toolchain rewrites against 5.6 on language rewrites, and the best model scores 47.0 out of 100 overall. The paper is a preprint submitted 2026-08-24 with no peer review and no independent replication, so both the protocol and the scores are unreviewed.
- **Why it matters:** The gap between toolchain rewrites and language rewrites is the number to use when scoping an agent-led migration.

### Study of 481 public CLAUDE.md files finds 4 to 16 percent of written security rules have a matching Claude Code built-in control

- **Category:** Paper
- **Status:** developing
- **Sources:** [primary](https://arxiv.org/abs/2608.23550)
- **Summary:** The study extracts security rules from 481 public `CLAUDE.md` files and estimates that 4 to 16 percent of them have a matching built-in Claude Code control, depending on the matching standard.
