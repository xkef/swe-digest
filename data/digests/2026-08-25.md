### Protocol Labs ends Shipyard's funding, and Kubo, Helia, Boxo, ipfs.io and dweb.link lose their maintainers on 2026-09-30

- **Category:** Infrastructure
- **Status:** confirmed
- **Sources:** [primary](https://ipshipyard.com/blog/2026-the-end-of-ipfs-at-shipyard/), [discussion](https://news.ycombinator.com/item?id=49421489)

The post states that ipfs.io, dweb.link, check.ipfs.network, delegated-ipfs.dev, the bootstrap nodes and Wikipedia-on-IPFS stop being operated by Shipyard, with Protocol Labs deciding their future.

### Microsoft Paint and Photos embed a server-issued GUID as an invisible pixel watermark in images generated locally on the device

- **Category:** Security
- **Status:** confirmed
- **Sources:** [primary](https://xusheng.dev/posts/reversing/mspaint_invisible_watermark/main/), [discussion](https://news.ycombinator.com/item?id=49421158)
- **Summary:** A reverse-engineering write-up traces a per-generation GUID from a moderation POST, through `Watermarker.dll`, into the pixels of images the local model produces, in Paint 11.2605.71.0 and Photos 2026.11060.2004.0. The author then finds the same value in the signed C2PA soft-binding assertion of a saved PNG, and obtained a live server response to confirm the identifier comes from the service rather than the device. The two applications differ on failure. Paint turns a watermarking failure into a failure of the whole generation, while Photos logs the error and returns the image unmarked.
- **Why it matters:** Local generation still requires a remote moderation call that carries the prompt and returns the per-generation identifier written into the pixels, so the image itself links back to a server-side record.

- **Category:** Security

- **Category:** Security
- **Status:** confirmed
- **Sources:** [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-21962), [KEV catalog](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json), [Oracle advisory](https://www.oracle.com/security-alerts/cpujan2026.html)
- **Summary:** CVE-2026-21962 is an access-control flaw in the Oracle HTTP Server and WebLogic Proxy Plug-in. CISA lists it as known exploited with a federal remediation deadline of 2026-08-27, and its required action is the generic instruction to apply mitigations per vendor instructions, follow applicable BOD 22-01 guidance for cloud services, or discontinue use of the product. NVD gives the affected versions as 12.2.1.4.0, 14.1.1.0.0 and 14.1.2.0.0, notes that the WebLogic Server Proxy Plug-in for IIS is affected in 12.2.1.4.0 only, and rates it CVSS 3.1 base 10.0 for an unauthenticated network attack with scope change. Oracle's January 2026 critical patch update is carried on the CVE record as the patch and vendor advisory.
- **Why it matters:** The fix shipped in Oracle's January 2026 critical patch update, so the exposed population is proxy plug-ins left unpatched for seven months rather than systems waiting on a vendor, and at CVSS 10.0 the attack needs no credentials.

- **Category:** Engineering post
- **Status:** confirmed
- **Sources:** [primary](https://fzakaria.com/2026/08/23/your-executable-is-a-sqlite-database), [discussion](https://news.ycombinator.com/item?id=49415271)
