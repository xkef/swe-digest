## Top stories

### ARC Prize measures GPT-6 Astra at 62.7 percent on ARC-AGI-3 under its neutral harness and 99.9 percent under the provider adapter

- **Category:** AI
- **Status:** confirmed
- **Sources:** [primary](https://arcprize.org/blog/astra), [discussion](https://news.ycombinator.com/item?id=49555691)
- **Blurb:** ARC Prize measured GPT-6 Astra at 62.7 percent on ARC-AGI-3 in its neutral harness and 99.9 percent via the provider adapter.
- **Summary:** ARC Prize reports a standard harness maximum of 62.7 percent at $26,098 and a Provider Adapter high setting of 99.9 percent at $18,817, so the provider-adapted run scored higher and cost less. ARC Prize states it will report both conditions on the leaderboard going forward and that it is not claiming AGI. Separate PRO-LONG runs gave the model a code sandbox that human test participants did not have.
- **Why it matters:** At matched maximum effort the same model on the same benchmark moves 35.9 points, 98.6 percent through the provider adapter against 62.7 percent in the neutral harness, so a single headline score does not describe what the model will do inside a given harness.
- **Follow-up:** Check whether the leaderboard publishes both harness conditions for later models.

### GitHub changes the rate-limited unauthenticated Git response from 403 to 401, with intermittent anonymous clone failures reported

- **Category:** Dev tools
- **Status:** confirmed
- **Sources:** [primary](https://github.com/orgs/community/discussions/206581), [discussion](https://news.ycombinator.com/item?id=49547193)
- **Blurb:** GitHub now returns 401 instead of 403 to rate-limited unauthenticated Git requests, and clones fail intermittently.
- **Summary:** A GitHub Community Admin states in discussion 206581 that rate-limited unauthenticated Git requests over HTTPS now return HTTP 401 where they previously returned 403, because 403 has no provision to retry with authentication and would block a request that Git could have authenticated. The reporter and the discussion title describe the clone failures as intermittent rather than constant.
- **Comments:** Commenters report that setting `git config http.version HTTP/1.1` resolves the failure with no credential change, and that git 2.53.0 does not reproduce it.
- **Why it matters:** A CI job cloning a public repository anonymously can fail intermittently at the negotiation step, and the 401 is what lets Git retry with credentials where the earlier 403 failed outright.
- **Follow-up:** Track whether GitHub identifies a cause for the intermittent failures.

### A preregistered audit reports LLM judge rankings on shared endpoints failing their own reliability gates

- **Category:** Paper
- **Status:** developing
- **Sources:** [primary](https://arxiv.org/abs/2609.04198)
- **Blurb:** A preregistered audit reports LLM judge rankings on hosted endpoints failing the reliability gates the authors set in advance.
- **Summary:** The paper reports an audit of hosted LLM judges across 52,988 request attempts, measuring whether rankings produced through shared endpoints hold across repeated runs. The authors registered reliability thresholds before collection and report that the measured rankings did not meet them.
- **Why it matters:** Anyone gating training data or a leaderboard on a hosted judge is treating a model name as a fixed instrument, and this audit measures how far that assumption failed.
- **Follow-up:** Watch for peer review, and for self-hosted replication under sustained load, the condition the paper reports it did not clear.

## Agentic coding

### Armature publishes 5,292 valid sessions measuring which third-party services coding agents install

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://armature.tech/blog/which-tools-coding-agents-install), [discussion](https://news.ycombinator.com/item?id=49557206)
- **Blurb:** Armature published 5,292 valid agent sessions showing repository language, not the stated requirement, decided which vendor won.
- **Summary:** Armature ran 16,893 sessions and kept 5,292 as valid, recording which third-party services a coding agent reaches for when asked to add a capability. In the email provider case the repository language rather than the stated requirement decided which vendor the agent picked. The validity judge and the simulated human in the loop were both Gemini 3.7 Flash, and Armature sells services for getting products picked by coding agents.
- **Why it matters:** The repository language, not the stated requirement, decided the winner in the email-provider case, so a team letting an agent pick a vendor is accepting a choice that varies with the codebase it was asked in.

### Hugging Face releases funes, a local-first memory layer built from existing coding-agent session traces

- **Category:** Agentic coding
- **Status:** confirmed
- **Sources:** [primary](https://huggingface.co/blog/funes), [code](https://github.com/huggingface/funes), [discussion](https://news.ycombinator.com/item?id=49560290)
- **Blurb:** Hugging Face released funes, a local-first memory layer that recalls original agent turns from existing session traces.
- **Summary:** funes indexes session traces a coding agent has already written and runs locally. Recall returns the original turn rather than a summary of it. The post's own benchmark reports the approach failing on one of two tasks.
- **Why it matters:** Recall returns the original turn rather than a summary, which is the difference from compaction that the post's own benchmark shows failing on one of two tasks.

### A pilot study reports coding agents route between grep and LSP by task, and that output shape moved success more than retrieval precision

- **Category:** Agentic coding
- **Status:** developing
- **Sources:** [primary](https://www.agentconnect.md/blog/grep-beat-lsp-harness/), [discussion](https://news.ycombinator.com/item?id=49560260)
- **Blurb:** A pilot study reports coding agents route between grep and LSP by task, and that output shape moved success more than precision.
- **Summary:** The study, dated 2026-08-12, runs two to three rollouts per cell across three Claude models and is labelled by its author as a preliminary pilot. Attaching source lines to the same semantic results cut follow-up file reads from 15.2 to 3.2 per episode and lifted pass@1 from 0.67 to 0.83. The author discloses a product interest in AgentConnect.

- **Follow-up:** Watch for a run with enough rollouts to separate the effect from noise.

### Daniel Lemire publishes a case where Python set and dict operations run in quadratic time

- **Category:** Languages
- **Status:** confirmed
- **Sources:** [primary](https://lemire.me/blog/2026/09/03/python-sets-and-dictionaries-can-have-quadratic-time-performance/), [discussion](https://news.ycombinator.com/item?id=49550115)
- **Blurb:** Daniel Lemire published a three-line Python case where set and dictionary operations run in quadratic rather than linear time.
- **Summary:** The post gives three lines that reproduce quadratic time in Python set and dictionary operations. A separate measurement in the same post records a plain dictionary lookup slowing from 21.8 to 201.9 nanoseconds per key under cache pressure alone, with no collisions involved.
- **Why it matters:** Container operations a Python service treats as constant time can degrade by an order of magnitude from data layout, which no algorithmic review of the code would show.
