## Top stories

### Meta Muse zero-day let any local process hijack the agent's account token

- **Category:** Security
- **Status:** confirmed
- **Sources:** [report](https://arstechnica.com/security/2026/09/muse-metas-extraordinarily-privileged-ai-assistant-has-a-serious-0-day/), [discussion](https://news.ycombinator.com/item?id=49802030)
- **Blurb:** A macOS zero-day in Meta's Muse assistant let any local process steal the account token of an agent holding email and payment authority.
- **Summary:** Patrick Wardle of the Objective-See Foundation found that any local app or code can change an undocumented Muse setting controlling the transcription endpoint, so pointing it at an attacker-run server hands over the account token. Muse holds WhatsApp, email, calendar, and purchase authority, and the reported delivery path is a ClickFix-style single command run by the user. Ars Technica reported that more than 12 hours after publication Meta said it had released a hotfix, and that Amazon began blocking Muse from its site and asked Meta to remove Amazon from the experience. Ars gives no affected or fixed Muse version numbers.
- **Why it matters:** A single ClickFix-style command could take over an agent holding WhatsApp, email, calendar, and purchase authority on macOS.
- **Follow-up:** Track whether Meta narrows the account token scope for Muse and whether it explains routing transcription through the cloud.

- **Status:** confirmed

Air Governance is the renamed JetBrains Central, which shipped about six months earlier. ### GPT-6 Astra breaks a German Army Enigma message unsolved since 2005

- **Category:** AI
- **Status:** confirmed
- **Sources:** [primary](https://www.cryptocellar.org/bgac/the-mvueh-break.html), [discussion](https://news.ycombinator.com/item?id=49801324)
- **Blurb:** GPT-6 Astra wrote its own Enigma simulator and Bombe, then recovered the key to a message unsolved since 2005.
- **Summary:** CryptoCellar documents GPT-6 Astra recovering the key to a German Army Enigma message open since 2005, after Carter Leffer directed the model to the unbroken message set and submitted the break for validation. ## Agentic coding

### Claude Code loads AGENTS.md only behind a remote feature flag

- **Category:** Agentic coding
- **Status:** developing
- **Sources:** [primary](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/), [issue](https://github.com/anthropics/claude-code/issues/95690), [discussion](https://news.ycombinator.com/item?id=49814947)
- **Blurb:** Claude Code loads AGENTS.md only when a remote flag is on, so telemetry-off and gateway setups silently skip project instructions.
- **Summary:** The post reports that Claude Code, which added AGENTS.md support in 2.1.277, reads the file from the working directory only when a remote feature gate is reachable and enabled, measured with canary words and a string search of the 2.1.280 bundle. The post collects and extends issue #95690, which names the Statsig gate `tengu_agents_md_mod`, so the two sources share one provenance chain rather than corroborating each other. Setting CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 or DISABLE_TELEMETRY=1 skips the file with no warning, and the post attributes the same behavior on third-party gateways, Bedrock, and Vertex to the issue. The issue is open and labelled enhancement, and the author labels the post ai-assisted.
- **Why it matters:** A telemetry-off install can run with no project instructions and no notice that a file was skipped, and a CLAUDE.md holding `@AGENTS.md` restores the read.
- **Follow-up:** Track whether Anthropic responds on issue #95690 or makes the AGENTS.md read independent of the gate.
